# Integrated firmware overview

The current and authoritative instructions are in `README.md` and `START_HERE.md`.

Firmware v2.0.0-alpha.9.0 is the single-station companion to RHEL gateway v1.8.0. It supports one Modbus Unit ID with 16 DI, 16 DO, 4 AI and 4 AO, and a redesigned 800x480 maritime operator screen.

Earlier alpha notes remain in the changelog files for provenance only.
