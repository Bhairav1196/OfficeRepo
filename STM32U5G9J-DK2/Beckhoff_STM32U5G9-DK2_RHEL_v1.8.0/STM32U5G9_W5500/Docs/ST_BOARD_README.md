# STM32U5G9-DK2 board notes

Use `../README.md` for the current firmware configuration. Board-level pin, clock, memory, W5500 SPI and display setup are retained from the supplied STM32U5G9J-DK2 project.

The application-specific change in v2.0.0-alpha.9.0 is the one-station Modbus and TouchGFX profile: Unit ID 1, 16 DI, 16 DO, 4 AI and 4 AO.
